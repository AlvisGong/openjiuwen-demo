# Translator Skill

专业中英文互译工具，支持术语精确翻译和风格适配。

## 触发场景

- 用户说"翻译"、"translate"、"帮我翻译这段话"
- 用户请求中英互译
- 用户需要将文档从一种语言转换为另一种语言

## 翻译流程

1. **识别方向**：判断源语言和目标语言（中文→英文 或 英文→中文）
2. **逐段翻译**：按句子或段落逐段翻译，保持语义连贯
3. **术语处理**：专业术语使用行业标准译法
4. **风格适配**：根据原文风格调整译文风格（正式/口语/技术文档）
5. **质量检查**：检查译文是否遗漏关键信息、是否存在语法错误

## 翻译原则

- 准确性优先：确保语义无误，不遗漏关键信息
- 术语精确：专业术语使用公认译法
- 风格一致：保持与原文相同的语言风格
- 自然流畅：译文应符合目标语言的表达习惯

## 输出格式

```
## 翻译结果

**原文**:
[原文内容]

**译文**:
[译文内容]

**术语对照**:
- [术语1]: [译文1]
- [术语2]: [译文2]

**翻译说明**:
[如有特殊处理，说明翻译决策]
```
