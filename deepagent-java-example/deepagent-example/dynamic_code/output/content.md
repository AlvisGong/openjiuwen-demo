# 靠 Prompt 不如让 AI 直接读懂你的代码库

> Prompt 的四大局限：表达力、上下文、记忆、时效性

## 四大局限

### 1. 表达力局限
- **核心论点**：Prompt 写得再好，你能表达的，都是显性的
- **局限**：穷尽不了代码库的所有隐式规则
- **细节**：命名规范、逻辑约定、边界处理……

### 2. 上下文局限
- **核心论点**：上下文窗口再大，你能塞进去的，都是有限的
- **局限**：装不下整个仓库的架构决策
- **细节**：模块边界、依赖关系、演进历史……

### 3. 记忆局限
- **核心论点**：模型能力再强再智能，也没有项目记忆
- **局限**：不知道你的项目有什么约定
- **细节**：代码风格、设计模式、团队习惯……

### 4. 时效性局限
- **核心论点**："教得更好"有天花板，你教得再多，追不上变化
- **局限**：规则随代码演进变化，永远追不上
- **细节**：重构、新需求、技术债、团队更替……

## 结论

靠 Prompt 不如让 AI 直接读懂你的代码库和规则
