# Text Analyzer Skill

文本分析工具，对输入文本进行多维度分析。

## 触发场景

- 用户说"分析这段文本"、"分析文章"、"提取关键词"
- 用户请求情感分析、摘要生成、风格评估
- 用户说"这段文字讲了什么"、"总结一下"

## 分析维度

### 1. 情感分析
- 识别文本的情感倾向：正面/负面/中性
- 分析情感强度：强/中/弱
- 列出触发情感的关键词

### 2. 关键词提取
- 提取 3-5 个核心关键词
- 按重要性排序
- 简要说明每个关键词的上下文含义

### 3. 摘要生成
- 生成一句话核心摘要
- 生成三句话详细摘要
- 保持原文关键信息不丢失

### 4. 风格评估
- 语言风格：正式/口语/学术/文学
- 句式复杂度：简单/中等/复杂
- 可读性评分（1-10）

## 输出格式

```
## 文本分析结果

### 情感分析
- 倾向: [正面/负面/中性]
- 强度: [强/中/弱]
- 关键词: [触发情感的词汇]

### 关键词
1. [关键词1] - [上下文含义]
2. [关键词2] - [上下文含义]
3. [关键词3] - [上下文含义]

### 摘要
- 一句话摘要: [核心内容]
- 详细摘要: [三句话展开]

### 风格评估
- 语言风格: [类型]
- 句式复杂度: [等级]
- 可读性: [评分]/10
```

## 分析流程

1. **阅读全文**：完整阅读输入文本
2. **情感判定**：识别情感倾向和触发词
3. **关键词提取**：定位核心概念
4. **摘要生成**：提炼核心信息和关键细节
5. **风格评估**：分析语言特征和可读性
6. **汇总输出**：按格式输出完整分析结果
