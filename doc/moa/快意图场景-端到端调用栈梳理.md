# 快意图场景（FAST_SELECT 快路径选择）——端到端调用栈梳理

> 场景定义（对应《意图中控流程图-SPI扩展点标注-v2.md》节点"快路径选择 FAST_SELECT — 单任务多候选"）：
> 单任务（cardinality=SINGLE）但意图命中多个候选，仲裁（ArbResult）保留 2~3 项时，不为消歧启动完整规划，
> 而是以 `moa_fast_select` 工具中断让用户选择；用户回复编号/名称后转入**单任务快路径**委派 L2 执行。
>

> - 运行日志：`demo\moa_agent\logs\run\run.log`，会话 `fs-run-e2e-426539`，2026-10-15 18:26:34 – 18:26:49
> - Mock L2 侧日志：`mock_versatile_server.py` 运行输出（versatile-account:18094）
> - 源码路径约定（相对 `d:\work\code-proj\openjiuwen-fin\moa\`，版本口径以 `0.1.1\` 为准）：
>   - `MOA` = `0.1.1\common\agents\moa-agent\src\main\java\com\moaagent`

## 1. 运行环境与请求入口

与《理财推荐场景-端到端调用栈梳理.md》相同（主服务 18098 / 沙箱 8321 / mock L2 18093-18097）。
本场景不涉及沙箱与本地 Skill（委派对象为 AGENT 类型候选，直连 L2）。

请求入口（两轮相同，仅 query 不同）：

```bash
POST http://127.0.0.1:18098/v1/demo/agents/finance-moa-agent/conversations/fs-run-e2e-426539
Content-Type: application/json

{"query":"我要还款","stream":true}
```

触发查询选择依据：demo 候选包 `l1-pack.yaml`（`MOA\resources\candidates\l1-pack.yaml`，9 张卡）中
"我要还款"同时命中 `cap.creditcard.repay`（关键词：还款/还钱/还信用卡）与 `cap.loan.repay`（关键词：还款/还钱/贷款），
两卡均为 kind=AGENT、risk=HIGH、adapter=versatile-account —— 这是候选包注释中标注的**歧义场景设计**。

## 2. 两轮总览

| 轮次 | 输入 | 时间 | 主链路 | 终态 |
|---|---|---|---|---|
| 第一轮 | 我要还款 | 18:26:34 → 18:26:36 | 召回 2 候选 → cardinality=SINGLE → LLM 仲裁 SHORTLISTED [1,2] → **path=FAST_SELECT** → `moa_fast_select` 选择中断 | `TASK_STATE_INPUT_REQUIRED` |
| 第二轮 | 2 | 18:26:45 → 18:26:49 | 恢复选择中断 → 解析"2"=贷款还款 → **转入单任务快路径** → v1-todo-1 A2A 委派 versatile-account → 同轮恢复 → 终态 | `TASK_STATE_COMPLETED` |

关键特征（与理财推荐快路径的差别）：

- 第一轮**不生成 todolist**——`FastCandidateSelection` 的设计目的就是"避免为单任务消歧启动完整规划"（类注释，`FastCandidateSelection.java:21`）；
- 选择后经 `delegateFast` 转入的快路径委派对象是 **AGENT** 候选（非 SKILL），由 `ExecutionEngine#dispatch` 直出 A2A 委派中断，无本地 NativeSkillAgent、无 result_script 沙箱环节，`normalizeResult` 对 AGENT 结果**原文透传**（`ExecutionEngine.java:154-161`）。

## 5. 公共机制说明

### 5.1 路由出口全景（DefaultRequestRoutingPolicy 的四类出口）

| 出口 | 条件 | 日志 reason | 后续路径 |
|---|---|---|---|
| `Decision.fast` | 候选数==1 ∧ SINGLE | SINGLE（或仲裁 SELECTED→`arbitrated_single`） | path=FAST：`delegateFast` 直接委派 |
| `Decision.select`（仲裁） | SINGLE ∧ 候选>1 ∧ 仲裁 SHORTLISTED | `arbitrated_multiple` | path=FAST_SELECT：选择中断（selectionLimit=3） |
| `Decision.select`（交接） | 召回为空但存在 handoff 候选（`route :35-37`） | `handoff_select_unresolved` | 选择中断（selectionLimit=32，`FastCandidateSelection.startHandoff`） |
| `Decision.slow` | 其余（多任务 / 仲裁不可用 / 超上限） | cardinality / `arbitration_no_match` / `arbitration_unavailable` | path=SLOW：完整规划（慢路径） |

FAST_SELECT 合法性五要素（`IntentRoutingRail#startRequest :232-235`）：action==SELECT ∧ 候选非空 ∧ size≤selectionLimit ∧ 全部 `engine.supports`；否则降级 SLOW（reason 标注 `executor_unsupported` 或 `arbitration_candidate_limit`，:260-264）。
