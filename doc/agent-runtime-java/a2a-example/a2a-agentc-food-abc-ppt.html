Agent C 餐饮推荐 A2A 全流程

User → Agent A → Agent B (流式/非流式路由) → Agent C → food_recommend 中断 → 确认 → 结果回传 C→B→A
1
用户 → Agent A: POST /v1/query {"conversation_id":"food-1","message":"Recommend a dish for our team lunch today","stream":false}
2
Agent A system-prompt: "必须调用 delegate_to_agentb" → LLM tool_call(delegate_to_agentb, {message:"Recommend a dish..."})
A2aDelegateRail → interrupt(agentName="agentb", _interrupt_kind="a2a_delegate")
3
Orchestrator (A) isCoordinatorInterrupt → true (a2a_delegate) → batchCoordinator.execute() → POST :18091/a2a → Agent B
4
Agent B 收到 "Recommend a dish..." → system-prompt: "dining 请求调用 delegate_to_agentc_streaming 或 nonstreaming"
→ LLM 根据请求内容选择工具: delegate_to_agentc_streaming (默认流式)
5
BToCDelegateRail 拦截工具调用:
toolCall.name == "delegate_to_agentc_streaming" → agentName = "agentc-streaming"
toolCall.name == "delegate_to_agentc_nonstreaming" → agentName = "agentc-nonstreaming"
→ interrupt(context:{agentName:"agentc-streaming", _interrupt_kind:"a2a_delegate"})
6
Orchestrator (B) → isCoordinatorInterrupt → true → batchCoordinator.execute()
A2ARemoteAgentClient: registry.get("agentc-streaming") → URL: http://localhost:18092/, streaming=true
→ POST :18092/a2a (SSE streaming) → Agent C
7
Agent C (DeepAgent) 收到 "Recommend a dish..." → system-prompt: "调用 food_recommend"
→ LLM tool_call(food_recommend, {request:"Recommend a dish for our team lunch today"})
8
FoodRecommendInterruptRail resolveInterrupt(resumeInput=null)
→ interrupt(message:"Agent C is ready to recommend food for: Recommend a dish... Confirm to continue.", context:{_interrupt_kind:"ask_user"})
注: resumeInput ≠ null 时直接执行 reject(recommendation), 不校验内容
9
中断冒泡 Orchestrator (C) → ask_user ≠ a2a_delegate → 透传
→ emitter.requiresInput() → Task = INPUT_REQUIRED
中断回传 C → B (Orchestrator saveShadow) → A (Orchestrator saveShadow) → HTTP 200
10
用户 收到: "Agent C is ready to recommend food for: Recommend a dish... Confirm to continue."
→ 回复 "yes" (或任意非 null 内容, FoodRecommendRail 不校验)
11
恢复链 用户 "yes" → A Orchestrator syncResumePending → resume(A shadow Task)
→ A2A callOutcome(taskId=B's, message="yes") → B Orchestrator syncResumePending → resume(B shadow Task)
→ A2A callOutcome(taskId=C's, message="yes") → Agent C
12
Agent C findStoredInterrupt → FoodRecommendInterruptRail.resolveInterrupt(resumeInput="yes")
resumeInput ≠ null → reject("Agent C received confirmation: yes; food recommendation: For 'Recommend a dish...', Agent C recommends Kung Pao chicken because it is easy to share.")
→ DeepAgent LLM 整理输出 → Task COMPLETED
13
结果回传 C→B→A C Task COMPLETED → B A2ARemoteAgentClient → B Orchestrator buildBatchResumeRequest
→ B A2aDelegateRail(BToC) reject(remoteResult) → B LLM 整理 → B Task COMPLETED → A A2ARemoteAgentClient
→ A Orchestrator buildBatchResumeRequest → A A2aDelegateRail reject(remoteResult)
14
Agent A LLM 收到工具结果 (verbatim, 不改写) → 生成最终回答
15
用户 收到: "Agent C recommends Kung Pao Chicken for your team lunch today! 🍗 It's a great choice because it's easy to share..."

BToCDelegateRail 路由选择

  • 工具名: delegate_to_agentc_streaming → agentName = agentc-streaming
  • 工具名: delegate_to_agentc_nonstreaming → agentName = agentc-nonstreaming
  • 注册表查找: registry.get(agentName) → URL + streaming 标志
  • Agent B yml: remote-agents 配置了两条路由, 指向同一 Agent C (:18092)

FoodRecommendInterruptRail 设计

  • 中断类型: ask_user (直接到达用户)
  • 首次: resumeInput=null → interrupt("Confirm to continue.")
  • 恢复: resumeInput ≠ null → 直接执行 reject(recommendation)
  • 不校验: 任意非 null 回复都执行 (与 CalcInterruptRail 不同)
  • 推荐结果: "For '...', Agent C recommends Kung Pao chicken because it is easy to share."

三重中断与 Shadow Task

  • A 层: A2aDelegateRail (a2a_delegate) → 远端调用 B
  • B 层: BToCDelegateRail (a2a_delegate) → 远端调用 C
  • C 层: FoodRecommendRail (ask_user) → 到达用户
  • Shadow Task A: 存 B 的 remoteTaskId (Member: agentc-streaming)
  • Shadow Task B: 存 C 的 remoteTaskId (Member: agentc-streaming)
  • 恢复路径: yes → A.resume → B.resume → C.resume (逐级恢复)
  • 结果回传: C COMPLETED → B reject → A reject → LLM 输出
