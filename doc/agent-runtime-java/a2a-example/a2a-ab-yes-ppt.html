A2A Agent 委派与中断恢复全流程

以 "What is 1+1?" 为例 — Agent A → Agent B → Calc → 用户确认 → 结果返回
1
用户 → Agent A (18090): POST /v1/query {"conversation_id":"a2a-test-1","message":"What is 1+1?","stream":false}
2
Agent A — system-prompt 指示"必须调用 delegate_to_agentb" → LLM 输出 tool_call(delegate_to_agentb, {message:"What is 1+1?"})
3
A2aDelegateRail 拦截工具调用 → interrupt(context: {agentName:"agentb", _interrupt_kind:"a2a_delegate"})
4
Orchestrator isCoordinatorInterrupt() → true (a2a_delegate) → batchCoordinator.execute() → A2ARemoteAgentClient.callOutcome()
5
A2A JSON-RPC POST http://localhost:18091/a2a → Agent B 收到 "What is 1+1?"
6
Agent B — system-prompt 指示"数学题调用 calc" → LLM 输出 tool_call(calc, {expression:"1+1"})
7
CalcInterruptRail resolveInterrupt(resumeInput=null) → interrupt(context:{_interrupt_kind:"ask_user"}, message:"Continue? Reply yes or no.")
8
Orchestrator (B) isCoordinatorInterrupt() → false (ask_user ≠ a2a_delegate) → 透传 → emitter.requiresInput() → Task = INPUT_REQUIRED
9
中断回传 Agent B → A2A SDK → Agent A A2ARemoteAgentClient → BatchCoordinator: saveShadow(WAITING_INPUT) → 构造中断 QueryResponse → HTTP 200
10
用户 收到: "Agent B is ready to calculate 1+1. Continue? Reply yes or no." → 回复 "yes"
11
恢复 Orchestrator syncResumePending → batchCoordinator.resume(shadow Task) → A2ARemoteAgentClient.callOutcome(taskId=Agent B's taskId, message="yes")
12
Agent B findStoredInterrupt → CalcInterruptRail.resolveInterrupt(resumeInput="yes") → AFFIRMATIVE → calculate("1+1")=2 → reject(result) → LLM: "The result is 2." → Task COMPLETED
13
Agent A 收到远端结果 → buildBatchResumeRequest(remoteToolResults) → A2aDelegateRail.reject(resumeInput) → LLM 原样输出
14
用户 收到最终结果: "The result of 1+1 is **2**."

中断类型路由

  • a2a_delegate A2aDelegateRail 产生 → Orchestrator 拦截 → 远端 A2A 调用
  • ask_user CalcInterruptRail 产生 → Orchestrator 透传 → 直接到达用户
  • 分叉点: isCoordinatorInterrupt() 检查 context._interrupt_kind

关键组件

  • A2aDelegateRail — Agent A 拦截委派工具, 写入 agentName="agentb"
  • CalcInterruptRail — Agent B 确认后计算, AFFIRMATIVE={"yes","ok",...}
  • BatchCoordinator — fan-out 远端调用, saveShadow 持久化
  • Shadow Task — 存远端 taskId + Member 状态, 供恢复读取
  • Task metadata — 中断数据存入 Task.status.message.metadata["_interrupt"]

核心设计

  • 双重中断: A 层 a2a_delegate (触发远端) + B 层 ask_user (到达用户)
  • 中断-恢复循环: Orchestrator while(true) 循环, 多次中断-恢复
  • reject(resumeInput): 远端结果直接回喂 LLM, 不真正执行工具
  • system-prompt: temperature=0.0 确保确定性行为
