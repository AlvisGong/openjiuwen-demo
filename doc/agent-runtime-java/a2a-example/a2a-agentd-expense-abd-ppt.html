End 无 responseTemplate → 嵌套 output 传递

  • End 配置: setEndComp("end", new End(), Map.of(...), null) — 第4参数 null
  • output 结构: 嵌套 Map {claim_id, policy_status, manual_decision, llm_report, auto_report}
  • D 侧: WorkflowOutput.getResult() → 返回嵌套 Map
  • Handler: rawResult instanceof WorkflowOutput → toQueryResponse(getResult())
  • 提取: extractContent(map, INVOKE_CONTENT_KEYS, true)
  • INVOKE_CONTENT_KEYS: ["output", "content", "response", "result", "data", "payload"]
  • "output" 命中: 递归提取嵌套 Map 中的文本内容
  • shouldUseMapFallback=true: 无 key 命中时 stringify 整个 Map
  • A2A 传输: 文本 → Task parts[TextPart] → RemoteCallOutcome.result
  • B/A 侧: remoteToolResults → Rail reject(resumeInput) → LLM

ExpensePolicyTool 策略检查

  • 限额: hotel=600, meal=300, transport=1000, other=1000
  • 判定: unit_price > limit → requires_approval=true
  • 本例: 800 > 600 → OVER_LIMIT
  • 合规: ≤ 600 → COMPLIANT → auto_approve

两轮对话对比

  • Round 1: 发起请求 → A→B→D 策略检查 → 超标中断 → 用户收到 INPUT_REQUIRED
  • Round 2: "approved" → 嵌套恢复 → LLM 报告 → End 嵌套 output → D→B→A → 用户收到报告
  • 合规场景: 无 Round 2, 单轮完成 (auto_approve → End → 直接返回)
  • 关键: 两轮使用同一 conversation_id, Shadow Task 保证状态延续
